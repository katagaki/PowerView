# App Store Listing (Japanese)

## Name

PowerView

## Subtitle

バッテリーの行方がわかる

## Promotional Text

iPhoneのsysdiagnoseを、見やすい日別のバッテリーレポートに変換。バッテリーを消費しているアプリや使い方を、すべてデバイス上の処理で見つけられます。

## Description

バッテリーが早くなくなった理由が気になったことはありませんか？iPhoneはすでに詳細な電源ログを記録しています。PowerViewは、そのログを読みやすいレポートにします。

sysdiagnoseを取得してPowerViewに共有すれば、最大1か月分のバッテリー履歴を日ごとに確認できます。すべての数値はシステム自身の電源ログから取得しているため、推測ではなく実際に起きたことがわかります。

毎日の状況を解説
• 1日ごとのバッテリー使用量、バッテリー駆動時間、画面オンの時間、総エネルギー
• 待機時と使用中の消費ペース、そのペースでフル充電がどれくらい持つか
• 普段の日と比べて、何が最もバッテリーを消費したかを示すハイライト

消費の原因を見つける
• アプリやシステムプロセスごとのエネルギーを、画面上とバックグラウンドに分けて表示
• プロセッサ、ディスプレイ、Wi-Fi、モバイル通信モデムなどのコンポーネント別エネルギー
• iOSがバックグラウンドでのCPUやディスクの大量使用を検知したアプリ

1時間ごとの推移
• 1日のバッテリー残量と、充電、画面オンの時間帯、設定の変更の表示
• バッテリー温度とそのピーク
• 画面の使用時間、常に画面オン、オーディオ、通知、スリープ解除、Wi-Fi、モバイル通信のレーン

画面に表示されていたもの
• どのアプリが画面に表示されていたかを分単位で示すタイムライン
• ニト単位の画面の明るさと周囲の明るさで、明るさがバッテリーに影響した時間帯を確認

通知とネットワーク
• 通知の多いアプリと、そのうちスリープを解除した件数
• 15分単位のWi-Fiとモバイルデータ通信、電波の強さ、5Gと4Gのすべての切り替え

充電の習慣
• 充電のタイミング、1回の充電時間、バッテリーが100%のままだった時間
• 一般的な開始時と終了時の残量、夜間の充電、有線とワイヤレスの充電器

安定性
• 同じsysdiagnoseに含まれるクラッシュ、応答なし、メモリ不足による終了、リソース制限のレポートを、日別とアプリ別に整理

任意の2日間を比較
• 2日間のバッテリー曲線を、電源を外した時点または時刻で揃えて表示
• すべての数値を並べて、何が変わったのかを確認

プライバシーを重視した設計
sysdiagnoseには個人データが含まれているため、PowerViewはすべての処理をiPhoneまたはiPad上で行います。レポートがアップロードされることも、デバイスの外に送信されることもありません。アカウントもトラッキングもありません。

使い方
1. 両方の音量ボタンとサイドボタンを約1.5秒間同時に押し続けて、sysdiagnoseを開始します。
2. 約10分後に、“設定” › “プライバシーとセキュリティ” › “解析と改善” › “解析データ”を開きます。
3. “sysdiagnose_”で始まるファイルを探して共有をタップし、PowerViewを選択します。

これらの手順はアプリ内でも案内します。電源ログには、約1か月分のバッテリー残量、約2週間分の1時間ごとの記録、直近1〜2日分の秒単位の詳細が保持されるため、確認したい日のあとは早めに取得してください。
