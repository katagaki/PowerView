# App Store Listing (Traditional Chinese)

## Name

PowerView

## Subtitle

看清電量都用到哪裡去了

## Promotional Text

將iPhone的sysdiagnose變成清楚的每日電池報告。找出消耗電量的App和使用習慣，全部在裝置上處理。

## Description

想知道電池為什麼這麼快就沒電了嗎？iPhone其實一直保留詳細的電源記錄。PowerView將它變成一份你看得懂的清楚報告。

擷取一份sysdiagnose，分享到PowerView，即可逐日查看長達一個月的電池歷史。所有數字都來自系統本身的電源記錄，你看到的是實際發生的情況，而不是估計值。

每一天，一目瞭然
• 每天的電池用量、電池供電時間、螢幕開啟時間和總能源用量
• 待機和使用時的耗電速度，以及以此速度充飽電可用多久
• 重點提示：與平常相比，什麼最耗電

找出耗電主因
• 每個App和系統程序的能源用量，分為在螢幕上和背景使用
• 各元件的能源用量：處理器、顯示器、Wi-Fi、行動數據機等
• 被iOS標示為在背景大量使用CPU或磁碟的App

逐小時查看
• 全天電池電量，並標出充電、螢幕開啟時段和設定變更
• 電池溫度及其峰值
• 螢幕使用時間、永遠顯示、音訊、通知、從睡眠喚醒、Wi-Fi和行動網路使用情況的分項圖表

螢幕上顯示了什麼
• 精確到分鐘的時間軸，顯示螢幕上是哪個App
• 以尼特為單位的螢幕亮度和環境光，看清亮度何時影響了電量

通知與網路
• 哪些App傳送的通知最多，以及其中多少則喚醒了手機
• 以15分鐘為單位的Wi-Fi和行動數據、訊號格數，以及每一次5G與4G切換

充電習慣
• 何時充電、每次充電多久，以及電池維持在100%的時間
• 常見的開始和結束電量、夜間充電，以及有線或無線充電器

穩定性
• 同一份sysdiagnose中的當機、無回應、記憶體不足關閉和資源限制報告，依日期和App分類

比較任兩天
• 對齊兩天的電池曲線，可從拔除電源時開始或依時間對齊
• 並排查看所有數據，找出變化所在

隱私優先
sysdiagnose包含個人資料，因此PowerView完全在你的iPhone或iPad上處理。你的報告絕不會上傳，也絕不會離開你的裝置。不需要帳號，沒有追蹤。

使用方式
1. 同時按住兩個音量按鈕和側邊按鈕約1.5秒，開始擷取sysdiagnose。
2. 約10分鐘後，打開「設定」›「隱私權與安全性」›「分析與改進功能」›「分析資料」。
3. 找到以「sysdiagnose_」開頭的檔案，點一下「分享」，然後選擇PowerView。

PowerView會在App內引導你完成這些步驟。電源記錄保留約一個月的電池電量、約兩週的每小時記錄，以及最近一兩天精確到秒的詳細資料，因此請在想查看的那一天之後盡快擷取。
