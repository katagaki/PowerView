# App Store Listing (Simplified Chinese)

## Name

PowerView

## Subtitle

看清电量都去哪儿了

## Promotional Text

将iPhone的sysdiagnose变成清晰的每日电池报告。找出消耗电量的App和使用习惯，全部在设备上处理。

## Description

想知道电池为什么这么快就没电了吗？iPhone其实一直在记录详细的电源日志。PowerView将它变成一份你看得懂的清晰报告。

采集一份sysdiagnose，共享到PowerView，即可逐日查看长达一个月的电池历史。所有数字都来自系统自身的电源日志，你看到的是实际发生的情况，而不是估算。

每一天，一目了然
• 每天的电池用量、电池供电时长、屏幕打开时长和总能耗
• 待机和使用时的耗电速度，以及按此速度充满电可用多久
• 重点提示：与平时相比，什么最耗电

找出耗电元凶
• 每个App和系统进程的能耗，分为屏幕活跃和后台使用
• 各组件的能耗：处理器、显示屏、Wi-Fi、蜂窝调制解调器等
• 被iOS标记为在后台大量占用CPU或磁盘的App

逐小时查看
• 全天电池电量，并标出充电、屏幕打开时段和设置更改
• 电池温度及其峰值
• 屏幕时间、全天候显示屏、音频、通知、从睡眠唤醒、Wi-Fi和蜂窝网络使用情况的分项图表

屏幕上显示了什么
• 精确到分钟的时间线，显示屏幕上是哪个App
• 以尼特为单位的屏幕亮度和环境光，看清亮度何时影响了电量

通知与网络
• 哪些App发送的通知最多，以及其中多少条唤醒了手机
• 以15分钟为单位的Wi-Fi和蜂窝数据、信号格数，以及每一次5G与4G切换

充电习惯
• 何时充电、每次充电多长时间，以及电池保持在100%的时长
• 常见的开始和结束电量、夜间充电，以及有线或无线充电器

稳定性
• 同一份sysdiagnose中的崩溃、无响应、内存不足关闭和资源限制报告，按日期和App分组

比较任意两天
• 对齐两天的电池曲线，可从拔下电源时开始或按时刻对齐
• 并排查看所有数据，找出变化所在

隐私优先
sysdiagnose包含个人数据，因此PowerView完全在你的iPhone或iPad上进行处理。你的报告绝不会被上传，也绝不会离开你的设备。无需账户，没有跟踪。

使用方法
1. 同时按住两个音量按钮和侧边按钮约1.5秒，开始采集sysdiagnose。
2. 约10分钟后，打开“设置”›“隐私与安全”›“分析与改进”›“分析数据”。
3. 找到以“sysdiagnose_”开头的文件，轻点“共享”，然后选取PowerView。

PowerView会在App内引导你完成这些步骤。电源日志保留约一个月的电池电量、约两周的每小时记录，以及最近一两天精确到秒的详情，因此请在想查看的那一天之后尽快采集。
